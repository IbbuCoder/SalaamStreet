# SalaamStreet 3.0.4 — MSA announcements for members

Release 3.0.4 · October 2026 · In the app: About → Updates (`SS.CHANGELOG` in `js/content.js`)

> **Before deploying:** run the updated `backend/supabase-schema.sql` (safe to
> re-run) — GitHub → Actions → "Deploy Supabase".

- **Members only.** `msa_feed` and `msa_image` answer only approved members,
  MSA admins and the approver (`msa_can_see_all`), never a banned account.
  Guests and signed-in non-members get nothing — not on the MSA page, not on
  Home. Every announcement is members-only, so the posting switch is gone.
- **How to join, on the MSA page:** students on the list sign in with their
  school email and are in automatically. To see announcements on a personal
  account instead, a new card says to ask **Ibrahim Ahmed** for the 6-digit
  meeting code — in person, by text ((464) 243-3663) or by email
  (ibrahim.asim.contact@gmail.com), shown with Text and Email buttons. The
  code works for 10 minutes.
- **The meeting code** (MSA admins) shows the clock time it changes —
  "Current code until 4:40 PM" — instead of a countdown. Codes change on the
  ten minutes (:00, :10, :20 …), as before.
- Old public announcement copies saved on devices are dropped.
- Existing members stay members.

Tests: `tests/msa.test.js` (members only, in the database), `tests/e2e.test.js`
(guest and non-member see the join cards and no announcements, members see
them and the Home card, the clock-time code).
