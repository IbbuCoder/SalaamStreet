# SalaamStreet 2.11.6 — NVHS MSA members

*Only real NVHS MSA members see members-only announcements.*

Release 2.11.6 · October 2026 · In the app: About → Updates (`SS.CHANGELOG` in `js/content.js`)

> **Before deploying:** run the updated `backend/supabase-schema.sql` in the
> Supabase SQL editor (safe to re-run). Then sign in as the MSA's approver,
> open the MSA page → **Manage**, paste the roster and tap **Save roster**.
> See [`backend/README-backend.md`](../../backend/README-backend.md#316--nvhs-msa-membership).

## Joining

- A **Join the NVHS MSA** card on the MSA page. Signed out, it offers sign-in
  (any account works — school accounts can't sign in to outside apps).
- Type your **first and last name**, plus the **meeting code** if you're at a
  meeting. The right code lets you in at once.
- The meeting code is **6 digits and changes every 10 minutes** (the one just
  replaced still works for its first minute). Only the approver can see it, on
  the Manage page, so it only works for people in the room. Five wrong codes in
  15 minutes stop code joining for that account for a while.
- No code? Send your name; the approver checks it.
- **One account per name.** If a name already belongs to a member, the request
  is flagged — even with the right code — and the student is told: *Please see
  Ibrahim in person at the next MSA meeting.*
- Membership lasts until **1 July**; everyone re-joins in the fall. Requests can
  be cancelled.

## Members-only announcements

- Posters have a new **Members only** switch. Those announcements (and their
  pictures) are left out by the database for anyone who isn't an approved
  member, a poster or the approver — they're never sent to other phones.

## For the approver (MSA page → Manage)

- The **live meeting code**, big enough to show a room, with a countdown and a
  bar to the next one.
- **Requests**, flagged ones first: the name typed, the account that asked,
  **On the roster / Not on the roster**, and Approve, Deny or Delete. Approving
  a flagged name is refused until the other account is removed — settle it in
  person first.
- **Members**, with how each joined (meeting code or approved by you) and Remove.
- **Roster**: paste the list from Google Classroom; headings, counts and blank
  lines are skipped. It's stored only in the private database, never in the
  app's code (which is public).

## Fixes

- The MSA page now redraws once a saved sign-in has been restored, so members
  and posters don't see the signed-out version after opening the app.

## Tests

- `tests/msa.test.js` — 6 new database tests: members-only posts and pictures
  reach only members, posters and the approver; requests with the roster check;
